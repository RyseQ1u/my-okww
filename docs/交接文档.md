
### 2.2 依赖安装

- **Python 环境**：使用 `D:\Dev\Python311\python.exe`（Python 3.11.2）。
  - 注意：项目 `requirements.txt` 是给 Python 3.12 编译的（`numpy==2.5.2`、`opencv==5.0.0.93` 等要求 ≥3.12），3.11 直接 `pip install -r requirements.txt` 会失败。
  - 本机另有 WorkBuddy 自带 Python 3.13（`C:\Users\46025\.workbuddy\binaries\python\versions\3.13.12\`），但清华镜像对 3.13 的索引同步不全（`ok-script`、`numpy` 均 "from versions: none"），因此**统一用 3.11**。
- **pip 源**：pypi.org 直连被代理拦，改用**清华镜像** `https://pypi.tuna.tsinghua.edu.cn/simple`（可通）。
- **关键依赖安装命令**（已全部成功）：

  ```bash
  # ok-script 本体 + mcp
  D:\Dev\Python311\python.exe -m pip install "ok-script==2.0.20" -i https://pypi.tuna.tsinghua.edu.cn/simple

  # opencv + openvino
  D:\Dev\Python311\python.exe -m pip install "opencv-python" "openvino" -i https://pypi.tuna.tsinghua.edu.cn/simple

  # Qt UI（qfluentwidgets 的正确包名是 PySide6-Fluent-Widgets）
  D:\Dev\Python311\python.exe -m pip install "PySide6-Fluent-Widgets" -i https://pypi.tuna.tsinghua.edu.cn/simple
  ```

- **踩坑**：
  1. `qfluentwidgets` 不是正确的 pip 包名，正确包名是 `PySide6-Fluent-Widgets`（代码里 `from qfluentwidgets import ...`）。
  2. 安装 PySide6 时，pip 卸载旧文件触发了 WorkBuddy 的「批量删除保护」被中断；分步安装（先 ok-script、再 opencv、再 fluent-widgets）绕过了该问题。
  3. 已装依赖清单（`pip list` 关键项）：`ok-script 2.0.20`、`numpy 2.3.1`、`opencv-python 5.0.0.93`、`openvino 2026.4.1`、`onnxocr-ppocrv5 0.0.22`、`PySide6 6.12.0`、`PySide6-Fluent-Widgets 1.11.3`、`pywin32 311`、`pycaw`、`psutil`、`pillow 11.2.1`。

### 2.3 源码 bug 修复

- **问题**：`src/task/FarmEchoTask.py` 第 411 行（上游 master 自带）有 f-string 语法错误，导致启动时 `import` 崩溃：

  ```python

      'combat_wait_time': ...,
  } }"
  ```

- **修复**：改为先构造 dict 再拼接：

  ```python
  profile = {

      'bypass_end_wait': self.bypass_end_wait,
      'treat_as_not_in_realm': self.treat_as_not_in_realm
  }
  self.log_info(f"profile: {boss} {profile}")
  ```

- **验证**：`python -m compileall -q src/ config.py main_debug.py` 全部通过。

## 四、下一步：阶段 1 —— 标定坐标

这是功能落地前最后一块拼图。核心任务：**在真实游戏里确定三个关键区域 + 三个按钮的归一化坐标**。

### 4.1 要标定的目标

| 常量 | 含义 | 用途 |
|---|---|---|
| `DETAIL_LEVEL_BOX` | 声骸详情页当前等级 | 判断是否达标 / 是否跳过 |
| `PREVIEW_LEVEL_BOX` | 强化面板预览等级 | 投料是否到位 |
| `CONFIRM_BOX` | 「强化」按钮 | 执行强化 |
| `ADD_MAT_BOX` | 「阶段放入」按钮 | 投料 |
| `FIRST_SLOT` | 列表第一格 | 定位声骸 |
| `SORT_BTN` | 排序按钮 | 滚回列表顶部 |

### 4.2 标定步骤

1. 启动 `main_debug.py`（见上）；
2. 游戏内进入 背包 → 声骸页，用筛选器选出待升级声骸、按等级升序排序；
3. 点开一件声骸进「培养」（强化）界面；
4. 点一次「阶段放入」，让界面出现预览等级；
5. 对当前画面做全屏 OCR dump，得到每个文字及其归一化坐标；
6. 将坐标回填到 `UpgradeEchoTask.py` 的类常量。

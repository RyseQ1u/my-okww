# 功能模块 01：列表导航与定位

> 关联代码：`UpgradeEchoTask` 的 `select_first_echo` / `back_to_list` / `back_to_list_top` / `in_echo_detail`

## 目标

在声骸列表中定位到"下一个待处理的声骸"，并能可靠地在「列表页 ↔ 强化页」之间往返。

## 范围

**In scope**：取列表第一格、判定是否在声骸详情页、从强化页返回列表、把列表滚回顶部。

**Out of scope**：列表滚动翻页（不识别、不逐格点击）、跳选特定声骸。

## 关键决策

1. **永远只取第一格**：依赖"用户预筛 + 等级升序"这一前置（见总体方案决策 1）。取第一格坐标 `FIRST_SLOT = (0.13, 0.21)`（沿用参考项目 `EnhanceEchoTask`）。
2. **用「培养」按钮作为"是否在声骸详情页"的探针**：`in_echo_detail()` = `ocr(TRAIN_BTN_BOX, match='培养')`。详情页右下角有此按钮，列表页/强化页没有，因此它能可靠区分状态。
3. **回列表后强制滚回顶部**：3.7 版本起，从培养界面 `esc` 回背包后，游戏会自动选中并滚动到刚强化的那件声骸，不再停在第一格。因此 `back_to_list_top()` 点排序按钮 `SORT_BTN` 两次把列表滚回顶部，再取第一格。
4. **`back_to_list()` 用 `esc` 循环 + 可选探针兜底**：循环最多 6 次发送 `esc`，中间用 `in_echo_detail()` 判断是否还在详情页，用 `echo_list_marker`（待标定模板）判断是否已回到列表。

## 依赖关系

- 依赖 `in_echo_detail` 的探针坐标 `TRAIN_BTN_BOX`（需标定）；
- 依赖游戏内热键 `esc`（返回）；
- 依赖 `FIRST_SLOT`、`SORT_BTN` 坐标（沿用参考项目，仍需实机复核）；
- 依赖前置：用户已筛选 + 等级升序排序。

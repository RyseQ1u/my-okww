# 功能模块 03：投料与目标判定

> 关联代码：`UpgradeEchoTask` 的 `enhance_to` / `find_add_mat` / 常量 `ADD_MAT_BOX`

## 目标

在强化界面里，把材料投到"预览等级 ≥ 目标等级 x"，并正确处理材料耗尽。

## 范围

**In scope**：循环点击「阶段放入」、读取预览等级、判定达标、检测材料耗尽。

**Out of scope**：精确退料（清空材料再逐个小料添加）到任意等级 —— 见总体方案"关于溢出"；经验表投放组合（决策 2 层级 B）。

## 关键决策

1. **「阶段放入」是投料粒度**：每点一次「阶段放入」（`ADD_MAT_BOX = (0.09, 0.60, 0.38, 0.86)`，沿用参考项目）投放一档材料，随后读预览等级。
2. **预览等级闭环（决策 2 层级 A）**：`enhance_to(target)` 循环最多 `MAX_BATCH = 8` 轮，每轮点一次阶段放入 → 读预览等级 → 若 `preview >= target` 则返回 `reached`。
3. **材料耗尽判定**：`find_add_mat()` 找不到「阶段放入」按钮 → 返回 `no_material`。
   - ⚠️ **风险**：`no_material` 无法区分"真材料耗尽"与"已达该稀有度等级上限"（此时按钮变灰）。当前在 `process_one` 里用 `is_material_shortage()`（弹窗 OCR 命中"不足/材料/贝币"）做二次确认，但"已达上限"可能无弹窗。见待办。
4. **溢出策略**：材料粒度固定，`preview` 可能一次超过 target；返回 `reached` 时若 `preview > target` 记日志提示"材料粒度所致"。是否接受由配置 `允许溢出` 控制（当前代码里该配置尚未在 `enhance_to` 内实际使用，见待办）。

## 依赖关系

- 依赖游戏内开启「阶段放入」；
- 依赖 `ADD_MAT_BOX`、`PREVIEW_LEVEL_BOX` 标定；
- 依赖模块 02 的预览等级读取正确。

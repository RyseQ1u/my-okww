# 功能模块 04：强化确认与复核

> 关联代码：`UpgradeEchoTask` 的 `confirm_enhance` / `confirm_enhance_available` / `process_one` 复核段 / 常量 `CONFIRM_BOX` / `DIALOG_BOX`

## 目标

投料达标后，执行强化，并**复核**强化后的真实等级确实 ≥ 目标等级；处理强化过程中的弹窗。

## 范围

**In scope**：点击「强化」按钮、清弹窗、强化后复核等级、未达标补投、上锁（可选）。

**Out of scope**：调谐（本功能关闭同步调谐）；副词条判定。

## 关键决策

1. **「强化」与「强化并调谐」兼容**：`confirm_enhance()` 依次尝试匹配 `("强化", "强化并调谐")`，因关闭同步调谐后按钮文案为「强化」，但保留「强化并调谐」兜底以兼容误开调谐的情况。
2. **强化后复核（关键闭环）**：`process_one` 在强化后读 `DETAIL_LEVEL_BOX` 复核等级；若 `new_level < target`，补一次 `enhance_to` + `confirm_enhance` 再复核。这是防止"预览达标但实际未达标"（如材料在强化瞬间被其他消耗）的兜底。
3. **弹窗处理**：`handle_dialogs()` 处理「不再提示」「点击任意位置返回」以及月卡弹窗（复用基类 `handle_monthly_card`）。循环上限 2 秒。
4. **上锁可选**：`达到目标后上锁` 配置为 True 时，达标后按 `c` 键上锁，便于事后人工复核。
5. **`confirm_enhance_available()` 就绪判定**：用"存在阶段放入 或 存在强化按钮"判断强化页已就绪，避免过早点击。

## 依赖关系

- 依赖游戏内关闭「同步调谐」（否则弹「调谐成功」需额外处理）；
- 依赖 `CONFIRM_BOX`、`DIALOG_BOX`、`DETAIL_LEVEL_BOX` 标定；
- 依赖模块 02（等级读取）、模块 03（投料）。

# 功能模块 02：等级读取与识别

> 关联代码：`UpgradeEchoTask` 的 `read_level` / `_parse_level` / 常量 `DETAIL_LEVEL_BOX` / `PREVIEW_LEVEL_BOX`

## 目标

可靠地读取两个等级值：**详情页当前等级**（判定是否已达标、决定是否跳过）和**强化面板预览等级**（投料是否到位）。

## 范围

**In scope**：OCR 提取等级数字、多帧读取、数值解析。

**Out of scope**：声骸等级之外的数值识别（材料数量、经验值等）；不做精确经验计算（那是决策 2 的层级 B，独立模块）。

## 关键决策

1. **归一化坐标区域**：`DETAIL_LEVEL_BOX` 与 `PREVIEW_LEVEL_BOX` 当前占位为同一区域 `(0.09, 0.10, 0.40, 0.20)`，**必须实机标定**——两者在游戏内位置不同（详情页等级在声骸面板左上，预览等级在强化面板投料结果区）。
2. **`max(nums)` 取最大值以"避开分母"**：`_parse_level` 用 `LEVEL_RE = r"(\d{1,2})"` 提取所有 1~2 位数字，再取 `max`。设计意图是避免把"1/25"中的"1"误读为等级。
   - ⚠️ **风险（待验证）**：区域若混入材料数量、等级上限 25、或其他 UI 数字，`max` 可能取到错误值（例如材料数量 999 会被 `\d{1,2}` 截断成 99）。必须确保标定区域**只包含等级文本**。
3. **多帧投票**：`read_level(box, retries=3)` 循环最多 3 帧，读到非 None 即返回。
   - ⚠️ **当前实现并非真正的"投票"**：它只是"读到就返回"，未做"连续多帧取众数"。若单帧误读为错误数字，会直接返回错误值。**待办：改为连续 N 帧取众数（出现次数最多的值）再返回。**

## 依赖关系

- 依赖框架 OCR（onnxocr）；
- 依赖 `DETAIL_LEVEL_BOX`、`PREVIEW_LEVEL_BOX` 标定；
- 依赖游戏语言为简体/繁体中文（数字识别与语言关系较小，但区域定位依赖中文 UI 布局）。

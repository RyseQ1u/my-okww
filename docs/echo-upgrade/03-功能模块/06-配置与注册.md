# 功能模块 06：配置与注册

> 关联代码：`UpgradeEchoTask.__init__`（`default_config` / `config_type` / `config_description`）、`config.py` 注册

## 目标

提供任务的可配置项，并把任务注册进 OK-WW，使其在 GUI 中可选择并运行。

## 范围

**In scope**：配置项定义、类型声明、描述、任务注册。

**Out of scope**：i18n 翻译（阶段 5 可选）；自定义配置控件类型（用框架现有 drop_down/bool/int）。

## 关键决策

1. **配置项清单**：

| 配置键 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `目标等级` | drop_down `[1..25]` | 15 | 运行时指定 x；用 drop_down 覆盖任意整数，无需自造数值控件 |
| `允许溢出` | bool | True | 材料粒度粗导致超 x 时是否接受 |
| `达到目标后上锁` | bool | False | 达标后按 c 上锁 |
| `材料耗尽时暂停` | bool | True | 结束后 `pause()` 而非直接退出 |
| `单件超时(秒)` | int | 90 | 防卡死 |
| `最大处理数量` | int | 200 | 防误触长时间运行 |

2. **「目标等级」用 drop_down 而非数值输入**：框架未确认是否支持数值输入控件，drop_down `options=list(range(1,26))` 稳妥覆盖 1~25。
3. **注册方式**：在 `config.py` 的 `onetime_tasks` 列表追加 `["src.task.UpgradeEchoTask", "UpgradeEchoTask"]`，放在 `EnhanceEchoTask` 之后（GUI 顺序即列表顺序）。
4. **语言**：`supported_languages = ["zh_CN", "zh_TW"]`，任务名/描述中文。

## 依赖关系

- 依赖框架的 `ConfigOption`/`config_type` 机制（GUI 自动生成面板）；
- 依赖 `config.py` 的 `onetime_tasks` 注册表；
- 依赖 `BaseWWTask` 的 `key_config`（Bag Key 等热键）。

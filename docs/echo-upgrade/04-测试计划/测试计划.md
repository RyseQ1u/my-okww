## 1. 标定步骤（阶段 1 前置）

1. 用 `python main_debug.py` 启动（绘制识别框）；
2. 进入背包声骸页，手动做一次「培养 → 阶段放入 → 强化」，全程截图存档；
3. 临时脚本 dump 全屏 OCR 及归一化坐标：
   ```python
   for t in self.ocr(0, 0, 1, 1):
       self.log_info(f"{t.name!r}  x={t.x/self.width:.3f} y={t.y/self.height:.3f} "
                     f"w={t.width/self.width:.3f} h={t.height/self.height:.3f}")
   ```
4. 从日志定位三个关键区域：**详情页等级**（`DETAIL_LEVEL_BOX`）、**强化预览等级**（`PREVIEW_LEVEL_BOX`）、**「强化」按钮**（`CONFIRM_BOX`），以及 `ADD_MAT_BOX`、`FIRST_SLOT`、`SORT_BTN`；
5. 写入类常量（归一化 0~1），并记录标定日期与游戏版本到本文件附录。

## 2. 功能用例

| ID | 用例 | 输入 | 期望 | 状态 |
|---|---|---|---|---|
| T1 | 单件冒烟 | 1 个 +0 声骸，x=5 | 停 +5，复核等级 == 5 | ⬜ |
| T2 | 混合队列 | 5 件初始 0/0/5/10/20，x=15 | 前 3 件处理，后 2 件（≥15）跳过 | ⬜ |
| T3 | 目标低于当前 | 全部 +20，x=5 | 立即结束，0 次操作 | ⬜ |
| T4 | 溢出路径 | x=7（非 5 的倍数），允许溢出=True | 停在可达等级并告警 | ⬜ |
| T5 | 材料耗尽 | 清空经验材料 | 优雅结束 + 通知，不红屏 | ⬜ |
| T6 | 贝币耗尽 | 保留材料清空贝币 | 同上，且不点确认 | ⬜ |
| T7 | 界面漂移 | 强化前插入月卡弹窗 | 自动关闭后继续 | ⬜ |
| T8 | 长稳 | 连续 50 件，x=25 | 无死循环、无内存增长、成功率 >95% | ⬜ |
| T9 | 断点续跑 | 中途手动停止后重启 | 从剩余件继续，不重复处理 | ⬜ |
| T10 | 已达等级上限 | 用接近稀有度上限的声骸 | 标记"已达上限"跳过，不误报材料耗尽 | ⬜ |
| T11 | OCR 干扰 | 区域含材料数量/等级上限数字 | 等级读取不受干扰 | ⬜ |
| T12 | 强化后未达标 | 人为制造预览达标实际未达标 | 补投一次后达标或记 fail | ⬜ |

## 4. 验收口径

- **单件**：升级成功且复核等级 ≥ 目标，无残留弹窗，无误上锁。
- **批量**：处理顺序正确，终止条件（首格等级 ≥ x）准确触发，无重复处理、无死循环。
- **异常**：资源不足优雅结束并通知；环境不可用才终止；单件失败不拖垮整体。
- **长稳**：50 件成功率 >95%，内存稳定。

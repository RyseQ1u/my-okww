## 四、代码级问题（按严重度）

### 🔴 P0：`PREVIEW_LEVEL_BOX` 与 `DETAIL_LEVEL_BOX` 相同，投料会失控

`UpgradeEchoTask.py` L33-34：

```python
DETAIL_LEVEL_BOX = (0.09, 0.10, 0.40, 0.20)   # 详情页当前等级文本
PREVIEW_LEVEL_BOX = (0.09, 0.10, 0.40, 0.20)  # 强化面板投料后的预览等级
```

两个本该是不同区域的框被写成同一个值，导致 `enhance_to()`（L142-158）的达标判断失效：

- 每次点「阶段放入」后读 `PREVIEW_LEVEL_BOX`，读到的其实是**当前等级**（未强化前恒小于 target）；
- `if preview >= target` 永远不成立 → 循环 `MAX_BATCH = 8` 次继续投料；
- 投料到「阶段放入」消失后返回 `"no_material"`，`run()` 以**"材料或贝币不足"**结束整个任务（L270-272）。

结果：第一件声骸就被灌到材料上限，任务误判为材料耗尽并停止。**这是材料浪费 + 功能不可用的双重问题，必须优先修。**

### 🟠 P1：「连续失败」判定不成立

L252：

```python
if self.fail_count >= self.MAX_RETRY and self.fail_count == self.done_count + self.fail_count:
```

后半段等价于 `done_count == 0`，即"只有一件都没成功过时才会因失败退出"。而 `fail_count` 在成功时从不归零，所以语义上不是"连续"而是"累计"。建议单独维护 `consecutive_fail`，`done` 时清零。

### 🟠 P1：`in_echo_detail()` 探针无法区分列表页与详情页

`in_echo_detail()` 探的是右下角「培养」按钮（L78-80），但既有代码证明**该按钮在背包声骸列表页同样存在**（`EnhanceEchoTask.run()` L62 就是用它判断"必须在背包声骸界面"）。

因此 `back_to_list()`（L113-121）里 `if self.in_echo_detail(): send_key("esc")` 在列表页也成立，最多连按 6 次 ESC，**有把背包整个退掉的风险**；之后 `select_first_echo()` 会在非列表页盲点 (0.13, 0.21)，`read_level()` 读空，最终以"无法读取等级"收场。

建议改用详情页独有元素做探针（如既有代码 `is_0_level()` 用的 `ocr(0.65, 0.35, 1, 0.57, match='声骸技能')`）。

### 🟡 P2：`find_one("echo_list_marker")` 特征不存在

L118 引用的 `echo_list_marker` 在 `ok_templates/` 中不存在（现有特征为 `echo_enhance`、`echo_locked`、`echo_not_locked`、`echo_enhance_confirm`、`yolo_echo_start` 等）。该分支恒不成立，"可选探针"等于没有，也是上述 ESC 连按的直接原因。要么用已有特征名，要么删掉这段。

### 🟡 P2：材料不足正则过宽

L25 `NOT_ENOUGH_RE = re.compile(r"(不足|材料|贝币)")` —— "材料"是强化面板的常规文案（如"材料"标签、"阶段放入材料"），会在正常界面误报材料不足。建议收窄为 `(材料不足|贝币不足|数量不足)`。

### ⚪ P3：若干一致性问题

- `confirm_enhance()`（L160-165）先试「强化」再试「强化并调谐」，但既有代码表明**必须关闭同步调谐**，否则只有「强化并调谐」。骨架注释也写了"不需要调谐"，两处口径不一致。
- `summary()`（L276-282）只要 `stop_reason` 非空就 `pause()`，包括"全部达到目标等级"这种正常结束；且未校验 `材料耗尽时暂停` 是否对应材料场景。
- `_parse_level()`（L85-91）取区域内所有数字的**最大值**。若框内混入稀有度"5"、等级"12"、经验"12000" 等，最大值会取错。建议按 `(?:Lv|等级)[^\d]*(\d{1,2})` 精确匹配。
- 「达到目标后上锁」仅 `send_key("c")` 盲按，既有代码用 `find_best_match_in_box(['echo_locked','echo_not_locked'])` 校验状态，建议对齐。
- 注册尚未完成：需在 `config.py` 的 `onetime_tasks` 追加 `["src.task.UpgradeEchoTask", "UpgradeEchoTask"]`，并把文件从 `docs/echo-upgrade/code/` 移到 `src/task/`。
